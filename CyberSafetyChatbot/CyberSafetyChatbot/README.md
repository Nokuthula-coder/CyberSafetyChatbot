# Cyber Safety Awareness Bot - Part 1- PROG6221
Student: Nokuthula Mtsweni ST10499051 | Module: PROG6221 POE Part 1

### Project Overview
This console chatbot educates South African Citizens about cybersecurity threats( passwords,phishing,safe browsing) as per Pieterse(2021)
research. It supports the national cybersecurity campaign.

## Features
- Voice greeting
-  ASCII art
- Personalised greeting
- Password safety responses
- Phishing responses
- Safe browsing response
- Input validation
- Coloured console interface

## How to Run
1. Clone/download the repository.
2. Open the solution in Visual Studio.
3. Ensure greeting.wav is available.
4. Build the project.
5. Press Ctrl + F5.


## Requirements
- Visual Studio
- Correct .NET version
- Windows audio support where required
