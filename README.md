## Project Overview
This application is a GUI-based Cybersecurity Awareness Assistant that
combines the functionality developed in Parts 1, 2 and 3.

## Final Features
### Part 1
- Voice greeting
- Cybersecurity identity / ASCII element
- Basic cybersecurity interaction
- Input validation
- 
### Part 2
- GUI interaction
- Keyword recognition
- Random responses
- Conversation flow
- Memory and recall
- Sentiment detection
- 
### Part 3
- MySQL Task Assistant
- Optional reminders
- Complete and delete task actions
- Cybersecurity quiz
- NLP simulation using string/phrase detection
- Activity Log
- 
## Database Setup
1. Install/start MySQL.
2. Run database_setup.sql.
3. Open DatabaseConfig.cs.
4. Replace YOUR_PASSWORD with the local MySQL password.
5. Run the application.
   
## How to Use
- Chat normally about cybersecurity in the Chat tab.
- Use the Tasks tab to create and manage cybersecurity tasks.
- Use the Cyber Quiz tab to start the quiz.
- Use Activity Log to view recent actions.
Example commands:
- Add a task to review privacy settings.
- Remind me to update my password tomorrow.
- Start the cyber quiz.
- Show my tasks.
- What have you done for me?
